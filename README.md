# AI-Powered Export Quality Compliance Checker

## Project Description

This project is a web-based academic prototype that
helps users perform preliminary export product checks.

## Technologies Used

- Frontend: HTML, CSS
- Backend: Python Flask
- Image Processing: Pillow
- OCR: Tesseract
- Database: SQLite
- PDF Generation: ReportLab

## Main Features

1. Product information form
2. Multiple image upload
3. Basic image quality analysis
4. OCR label text extraction
5. Preliminary compliance scoring
6. Assessment status and observations
7. PDF report generation
8. Assessment history
